# 腾讯开悟强化学习项目

腾讯开悟平台上的强化学习实验与比赛代码，包含峡谷漫步、重返秘境、峡谷追猎，以及王者荣耀 1v1、3v3 五个项目。内容覆盖路径规划、资源收集、追逃生存和多智能体对抗，保留各项目的算法实现、配置、设计说明与实验展示。

王者荣耀赛道在 2026 年比赛中取得 **北部赛区区域决赛第 1、全国总决赛第 9** 的成绩，对应的 1v1 和 3v3 实现分别整理在独立目录中。

## 项目导航

| 项目 | 主要任务 | 主要方法 | 详细说明 |
| --- | --- | --- | --- |
| [峡谷漫步](gorge_walk/) | 在网格地图中避障、收集宝箱并抵达终点 | PPO、基于已知地图的动态规划 | [README](gorge_walk/introduction/README.md) |
| [重返秘境](back_to_the_realm/) | 在局部视野下探索地图，利用闪现和增益完成导航与采集 | CNN、Dueling / Double DQN、阶段目标辅助 | [README](back_to_the_realm/introduction/README.md) |
| [峡谷追猎](gorge_chase/) | 躲避双怪追击，在生存与宝箱收益之间选择路线 | CNN + MLP PPO、局部 BFS、闪现逃生规则 | [README](gorge_chase/introduction/README.md) |
| [王者荣耀 1v1](honor_of_kings_1v1/) | 控制单名英雄完成对线、交战和推塔 | 结构化特征、LSTM、目标注意力、Dual-clip PPO | [README](honor_of_kings_1v1/introduction/README.md) |
| [王者荣耀 3v3](honor_of_kings_3v3/) | 控制两名英雄并调度官方队友，协作摧毁敌方水晶 | CNN、双路 PSCN、GRU、多价值估计、团队指令策略 | [README](honor_of_kings_3v3/introduction/README.md) |

### 峡谷漫步

对比交互学习与确定性规划两种任务求解方式。PPO 使用位置、目标距离、局部障碍和访问记忆学习移动策略；动态规划利用地图转移表与预设宝箱顺序生成策略，作为固定场景下的最终方案。

### 重返秘境

结合局部地图 CNN 和位置、目标、技能等向量特征估计动作价值，通过探索覆盖、宝箱收集和终点奖励引导导航。仓库保留两套 DQN 实现，其中阶段目标辅助版本还结合目标选择、方向偏置和规则约束。

### 峡谷追猎

同时考虑怪物位置、接近趋势与地形通路，使用欧氏距离、局部 BFS 路径距离和近邻判断描述威胁。PPO 负责持续决策，规则辅助处理紧急闪现、近怪避让和邻格取宝。

### 王者荣耀 1v1

使用 4833 维结构化特征表达英雄、兵线、防御塔、子弹和目标候选，通过统一视角、全图与中央区域两种尺度的位置编码描述战场。MLP 与 LSTM 融合后输出动作和目标，结合开局跟线、技能修正及低血撤退规则改善对线行为。

### 王者荣耀 3v3

每名可控英雄使用 10157 维图像与结构化观测，团队和个体特征经独立残差 PSCN 与 GRU 建模。普通策略按英雄身份路由，团队指令网络负责调度官方队友，并通过混合主价值与五类辅助价值学习协作和资源转化。

## 实验与评测结果

以下为其余项目的实验指标，与比赛名次分别列出。

| 项目 | 设置与结果 |
| --- | --- |
| 峡谷漫步 | PPO 约一小时训练后得分可达约 800 分，但未稳定收敛；最终采用动态规划完成固定场景任务 |

环境准备、算法入口选择、历史权重配置、训练检查与评测记录方式见[训练与复现说明](TRAINING_AND_REPRODUCTION.md)。首次运行前，请先核对所选项目的平台配置、模型路径和对手模型是否可用。

## 目录与阅读方式

每个项目独立保留算法目录和平台配置：

```text
Tencent_LM/
├── gorge_walk/
├── back_to_the_realm/
├── gorge_chase/
├── honor_of_kings_1v1/
└── honor_of_kings_3v3/
```

各项目的 `introduction/PROJECT_INTRODUCTION.md` 介绍任务规则，`introduction/README.md` 说明具体实现和实验，`introduction/images/` 保存对应展示素材。算法代码位于 `agent_*`，平台入口及运行配置位于 `conf/`。

代码依赖腾讯开悟对应赛题的运行环境及 SDK。运行时以所选项目目录作为工作目录，并检查算法入口、环境配置和模型路径；仅安装 PyTorch 不足以独立启动完整训练。
