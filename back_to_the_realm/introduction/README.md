# 重返秘境 · 任务简介

本项目训练一个在局部视野下导航、收集宝箱并抵达终点的智能体。智能体需要通过探索建立对道路和障碍的认识，利用移动、闪现和加速增益，在有限步数内完成收益较高的路线。

## 环境与操作

- 地图包含起点、终点、道路、障碍、宝箱和地图中心的加速增益。
- 控制角色为鲁班，观察范围为以自身为中心的 51 × 51 区域，没有完整的全局视角。
- 支持八方向移动，每次动作持续执行 3 帧，组成一个环境 step。碰到障碍时可能沿边缘移动。
- 提供 13 个可配置宝箱点位，可以调整宝箱数量及随机性。
- 超级闪现允许向指定方向远距离位移，受冷却限制；加速增益可以在一段时间内提高移动速度。

## 训练要解决的问题

学习从局部观察中选择行进方向，减少绕路和碰撞；在绕路取宝箱与及时到达终点之间作出判断，并学习使用闪现穿越地形、利用加速提高行进效率。连续多帧执行动作也要求策略考虑移动后的实际落点。

## 成功条件与评分

在最大步数内（包括最大步数）抵达终点，任务才算成功。终点奖励为 150 分，每个宝箱 100 分，剩余步数按每步 0.2 分计入成绩：

`总分 = 150 + (最大步数 - 完成步数) × 0.2 + 宝箱数量 × 100`

超时未到终点，任务得分为 0。上述为任务评分，代码中的训练奖励可以另外设计。
