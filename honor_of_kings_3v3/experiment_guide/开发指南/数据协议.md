# 数据协议

为了便于读取原始帧状态、构建特征和发送协作指令，下面列出常用协议字段。

## 原始帧状态信息

原始帧状态对应 `observation["frame_state"]`。

| 类型 | 字段名 | 字段类型 | 说明 |
| --- | --- | --- | --- |
| `FrameState` | `frameNo` / `frame_no` | `signed int` | 当前帧号。 |
| `FrameState` | `hero_states` | `vector<HeroState>` | 英雄状态列表。 |
| `FrameState` | `npc_states` | `vector<ActorState>` | 非英雄角色状态列表，包括野怪、小兵、防御塔等。 |
| `FrameState` | `bullets` | `vector<Bullet>` | 子弹列表。 |
| `FrameState` | `cakes` | `vector<Cake>` | 功能物件列表，如血包等。 |
| `FrameState` | `equip_infos` | `vector<EquipInfo>` | 装备信息列表。 |
| `FrameState` | `frame_action` | `FrameAction` | 死亡事件。 |
| `FrameState` | `monster_spawn_infos` | `vector<MonsterSpawnInfo>` | 怪物出生状态。 |
| `FrameState` | `collaboration_state` | `CollaborationState` | 协作状态。 |

## 协作状态

`collaboration_state` 记录当前微观协作指令、冷却和最近发送信息。

| 类型 | 字段名 | 字段类型 | 说明 |
| --- | --- | --- | --- |
| `CollaborationState` | `max_duration` | `signed int` | 指令最大持续时间。 |
| `CollaborationState` | `micro_cd` | `signed int` | 微观指令冷却时间。 |
| `CollaborationState` | `macro_cd` | `signed int` | 宏观指令冷却时间，暂未开放。 |
| `CollaborationState` | `micro_state` | `vector<CollaborationMicroState>` | 当前微观指令状态。 |
| `CollaborationState` | `macro_state` | `vector<CollaborationMacroState>` | 当前宏观指令状态，暂未开放。 |
| `CollaborationState` | `micro_last` | `vector<CollaborationLastSend>` | 最近一次微观指令发送信息。 |
| `CollaborationState` | `macro_last` | `vector<CollaborationLastSend>` | 最近一次宏观指令发送信息，暂未开放。 |

## 微观协作指令状态

| 类型 | 字段名 | 字段类型 | 说明 |
| --- | --- | --- | --- |
| `CollaborationMicroState` | `sender` | `signed int` | 当前指令发送者 runtime\_id。 |
| `CollaborationMicroState` | `receiver` | `signed int` | 当前指令接收者 runtime\_id。 |
| `CollaborationMicroState` | `end_frame` | `signed int` | 当前指令结束帧。 |
| `CollaborationMicroState` | `target_position` | `VInt3` | 目标位置。 |
| `CollaborationMicroState` | `target_runtime_id` | `signed int` | 目标单位 runtime\_id。 |

| 类型 | 字段名 | 字段类型 | 说明 |
| --- | --- | --- | --- |
| `CollaborationLastSend` | `sender` | `signed int` | 最近一次指令发送者 runtime\_id。 |
| `CollaborationLastSend` | `frame_no` | `signed int` | 最近一次指令发送帧号。 |

### 协作状态注意事项

- 指令超过最大持续时间后会从帧状态中清除。
- 中断指令会清除当前发送者对官方智能体发送的命令。
- 官方智能体英雄死亡不会自动清除当前通信指令或通信状态。
- 目标单位初始即无效时，不更新 `collaboration_state`，也不计入指令冷却。

## 协作指令动作

智能体返回的协作指令为 4 元素列表：

```python
[action_type, target_runtime_id, position_x, position_z]
```

| 下标 | 字段 | 说明 |
| --- | --- | --- |
| `0` | `action_type` | 协作动作类型。 |
| `1` | `target_runtime_id` | 目标单位 runtime\_id。 |
| `2` | `position_x` | 目标位置 X 坐标。 |
| `3` | `position_z` | 目标位置 Z 坐标。 |

| action\_type | 含义 | 说明 |
| --- | --- | --- |
| `0` | 无动作 | 不发送协作指令。 |
| `1` | 指定目标对象 | 指令官方智能体攻击或跟随目标单位。 |
| `2` | 指定目标位置 | 指令官方智能体移动到指定坐标。 |
| `3` | 中断 | 取消当前协作指令。 |

### CmdPkg — 指令信息

`Hero.real_cmd` 内每一个元素为一个 `CmdPkg`，表示英雄实际执行的指令。各子字段按 `command_type` 取值解释对应字段：

| 字段名 | 字段类型 | 备注 |
| --- | --- | --- |
| command\_type | int | 指令类型 |
| move\_pos | object | 指向目标移动命令参数 `{ destPos: VInt3 }` |
| move\_dir | object | 指向方向移动命令参数 `{ degree: int }` |
| attack\_common | object | 普通攻击命令参数 `{ start: int, actorID: int }`（`start`：0 按下，1 抬起） |
| attack\_topos | object | 移动施法命令参数 `{ destPos: VInt3 }` |
| attack\_actor | object | 锁定目标命令参数 `{ actorID: int }` |
| obj\_skill | object | 目标性技能命令参数 `{ skillID: int, actorID: int, slotType: int }` |
| dir\_skill | object | 方向性技能命令参数 `{ skillID: int, actorID: int, slotType: int, degree: int }` |
| pos\_skill | object | 位置性技能命令参数 `{ skillID: int, destPos: VInt3, slotType: int }` |
| learn\_skill | object | 学习技能命令参数 `{ slotType: int, level: int }` |
| buy\_equip | object | 购买装备命令参数 `{ equipId: int, obj_id: int }` |
| sell\_equip | object | 出售装备命令参数 `{ equipIndex: int }` |
| charge\_skill | object | 蓄力技能命令参数 `{ slotType: int, state: int, degree: int }` |
