# 王者荣耀 3v3 · 任务简介

本项目训练一个能够完成团队作战和通信协作的智能体。在三人队伍中，选手模型直接控制两名英雄，并通过协作指令调度第三名官方智能体英雄，最终摧毁敌方水晶。

## 环境与操作

- 使用长平攻防战地图，包含兵线、野区、防御塔、水晶及可争夺的地图资源。
- 英雄阵容由马可波罗、貂蝉和铠组成；不同阵容决定其中哪两名由选手模型直接控制。
- 模型同时处理两名英雄的移动、攻击和技能决策，还需要向官方英雄发送有效协作指令。
- 官方英雄在没有有效指令时会向己方泉水移动；收到有效指令后才按要求行动。指令存在冷却、持续时间及目标有效性等约束。

## 训练要解决的问题

学习两名可控英雄之间的分工和配合，并让官方队友在合适时间参与战斗、资源争夺和推进。策略需要协调个人生存、团队经济、战斗收益与建筑目标，也要适应不同控制阵容和换边后的局势。

## 胜负与评价

摧毁敌方水晶获胜，胜利得 1 分，失败或超时得 0 分。当前指南采用三种己方阵容与三种对方阵容组合并换边，一轮评估包含 18 小局。

训练应以多阵容下的团队胜率为最终评价依据，个体奖励和中间战斗指标用于辅助分析。
